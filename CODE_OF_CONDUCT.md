# Code of conduct

Treat contributors and users with respect regardless of background, identity or experience. Be constructive and specific in reviews. Harassment, threats, discriminatory language, personal attacks and publication of private information are not acceptable.

Maintainers may edit or remove harmful content and restrict participation when needed, applying rules fairly. Raise ordinary conduct concerns through a repository issue without repeating harmful or private material. For sensitive concerns, use the maintainer's available private contact route on their GitHub profile; never publish another person's private information. If a private route is unavailable, do not post sensitive details publicly.
